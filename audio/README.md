# 主題背景音樂

本目錄各主題循環背景音樂（約 33–58 秒、剛好一節、單聲道、64 kbps MP3，頭尾淡入淡出方便循環）。新增場合沿用既有曲目。寫信頁點選主題後才載入，預設播放音量 0.35、循環播放，不預先快取。

除「生日」外，都是主恢復中英文詩歌的詩歌曲調（公有領域），用 Wikimedia Commons 上 Rabanus Flavus 的 CC0 四部和聲 MIDI，以 FluidSynth＋FluidR3_GM 合成鋼琴或弦樂音色，不必署名。生日曲旋律為公有領域，MIDI 同樣是 CC0。逐首曲名、詩歌首數與來源見專案根目錄 `README.md` 的「背景音樂」一節。畫面只在使用說明最下方以一行小字署名，其他地方不特別標示。

檔名對應信紙主題：`rose` 素雅、`sky` 晴空、`kraft` 牛皮、`mint` 薄荷、`winter` 冬季、`midautumn` 中秋、`duanwu` 端午、`chuxi` 除夕、`winterbreak` 寒假、`summer` 暑假、`newyear` 新春、`thanks` 感恩、`grad` 畢業、`birthday` 生日、`gospel` 福音、`love` 愛情、`shepherd` 牧養、`build` 建造、`farewell` 離別、`distance` 遠距、`reunion` 重逢、`missing` 思念。舊版 `xmas` 聖誕音檔仍保留，選單已不顯示。
